## Getting started

- You first need to copy `.env.example` to `.env` and edit it.
  - You can find your account ID on the [Cloudflare Dashboard](https://dash.cloudflare.com/) by going to Account home, clicking the search bar or pressing CMD/CTRL + K, and typing Copy account ID. ([Find account and zone ids](https://developers.cloudflare.com/fundamentals/account/find-account-and-zone-ids/))
- And now, you can edit your `wrangler.jsonc`
